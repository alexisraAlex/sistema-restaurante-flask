# Sistema de restaurante

Aplicación web académica con Flask para gestionar clientes, órdenes y un panel de ventas.

## Configuración local

1. Crea un entorno virtual e instala `requirements.txt`.
2. Copia `.env.example` a `.env` y define `FLASK_SECRET_KEY` y, si usarás sugerencias de recetas, `SPOONACULAR_API_KEY`.
3. Ejecuta `python app.py`.

La base de datos local y las credenciales no se incluyen en este repositorio.
